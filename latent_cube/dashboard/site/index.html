The recording

No data has been loaded. Counts and measurements will appear only after a successful build.

An activation is a number produced inside the model while it processes text. A token is a piece of text, sometimes only part of a word. At each token, the residual stream is a list of 2,560 numbers passed through 32 processing layers. Each layer adds information from a token mixer and an MLP.

A token mixer combines information across text positions. Every fourth layer uses full attention; the others use Gated DeltaNet memory. An MLP is a feed-forward calculation applied to each token. Here, its 9,216 intermediate values are called neurons. A large neuron value is not, on its own, evidence of a particular meaning.

Free means the recording contains the model’s own reply. Forced means we supplied a reply: “Okay.” or “The capital of France is Paris.” The model’s original free reply is still shown beside it. Thinking was off; the empty thinking block remains visible in the token list.

How large is the stream?

The norm is the length of a vector of numbers. Here it measures size, not meaning. R1 is the stream after a layer; R2 is the mixer’s added vector; R5 is the MLP’s added vector. Their lengths do not add like ordinary positive numbers: vectors can reinforce or cancel each other.

If the model stopped here…

The logit lens applies the model’s final normalization and output layer to an earlier residual stream. A logit is a token score; softmax converts the scores into probabilities. Each cell asks which token this readout predicts next, after the column’s token. Early layers were not trained to be read this way; this is a diagnostic, not proof of what the model “knows.”

x is R1; w is the learned final normalization weight; E is the learned token embedding matrix, also used by the output layer. Probabilities are over all 248,320 vocabulary entries. Rank 1 means no token has a larger score.

Where does attention look?

An attention head assigns weights to earlier token positions. Each query row describes the token doing the looking; key columns are the tokens it can look at. Larger weights are brighter. This is the recorded softmax pattern, not a measure of causal importance. DeltaNet layers have no attention matrix in this capture.

Cosine similarity compares the directions of two residual vectors. 1 means the same direction; 0 means perpendicular; −1 means opposite. Similar direction alone does not establish a shared mathematical concept.
