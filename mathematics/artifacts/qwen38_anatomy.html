Qwen3.8-27B, opened up

One long column of 5,120 numbers travels through 64 blocks. Every block reads that column, computes something, and adds its result back. That is the whole machine; the rest is detail about what each block computes.

The path of one token

Text is cut into tokens. Each token is swapped for a row of the embedding table, which gives the first column of 5,120 numbers. That column is the residual stream. After 64 blocks it is normalised and multiplied by one last matrix that scores every possible next token.

The 64 blocks

Blocks come in two kinds, in a fixed rhythm: three linear-attention blocks, then one full-attention block, repeated sixteen times. Select a block to see what it is.

linear attention (48) full attention (16): blocks 3, 7, 11 … 63 blocks where your runs saved the stream

Inside one block

Both kinds share the same skeleton. The stream is copied, normalised, passed through a mixer that lets tokens exchange information, and the result is added back. Then the same again with an MLP, which works on each token alone. Only the mixer differs between the two kinds.

The matrices, drawn to scale

Every rectangle is one weight matrix. Width is the size of the vector going in, height the size coming out, at one pixel per 128 numbers. A matrix is a machine that turns one vector into another; its shape tells you what goes in and what comes out.

The MLP, in every one of the 64 blocks

The MLP computes down( silu(gate(x)) × up(x) ): two projections up to 17,408 numbers, multiplied together element by element, then one projection back down.

Where the 26.9 billion parameters sit

Almost two thirds of the model is MLP. Attention, which gets most of the discussion, is a little over a quarter. The total from these shapes is 26,895,998,464, which matches the 26.90 B the pod reported after loading.

What a hook hands you

A hook placed on a block returns the residual stream as it leaves that block: one row of 5,120 numbers for every token, prompt and generated text together. Your two runs saved that at five blocks. Those five were a placeholder choice of evenly spaced blocks; all 64 can be saved for about 680 MB on the parabola run.

Words used on this page

Token
A piece of text, often a word fragment. This model writes numbers one digit per token, so "16" is two tokens.
Residual stream
The 5,120-number vector kept for each token position. It is the only thing blocks share with each other.
Block (layer)
One mixer plus one MLP, each wrapped in the copy, normalise, compute, add pattern.
RMSNorm
Rescales a vector so its overall size is about 1, then multiplies each entry by a learned weight. It keeps the numbers in a workable range.
Head
One of several independent copies of the attention computation, each working in its own small slice of dimensions (256 or 128 here).
Gate
A number between 0 and 1, computed from the input, that scales another signal. It lets the model decide how much of something to pass on.
Logits
The 248,320 scores that come out at the end, one per possible next token. The highest score is the model's first choice.
